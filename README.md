# office-tips
# Office 小技辞典（試作品 v0.1）

Windows版 Microsoft 365向け、Excel・Word・PowerPointの小技を検索できる静的Webアプリです。

## 使い方

`index.html` をブラウザで開いてください。検索、アプリ別フィルター、お気に入り（ブラウザ内保存）、手順表示、印刷が使えます。

## GitHub Pages公開

1. GitHubで公開用リポジトリを作る。
2. `index.html` をリポジトリのルートにアップロードする。
3. Settings → Pages → Build and deployment → Deploy from a branch を選択する。
4. Branch `main`、フォルダー `/(root)` を選択して保存する。

## 注意

- 現時点で収録しているのは代表的な12件のみです。137項目の全件版ではありません。
- 図解は一部の簡易イメージのみで、実際の操作画面のスクリーンショットではありません。
- Microsoft 365のバージョンや表示設定によって、メニュー名称や位置が異なる場合があります。
- GitHub Pagesの公開リポジトリには業務上の機密情報を置かないでください。
