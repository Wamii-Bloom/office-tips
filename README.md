# Office 小技辞典 | Bloom Wamii

Excel・Word・PowerPointの「これ、どうやるんだっけ？」を、やりたいことからすぐ探せる無料のWebツールです。

**アプリを開く：** https://wamii-bloom.github.io/office-tips/

## できること

- **やりたいことから探す：** キーワード検索やアプリ別の絞り込みで操作を探せます。
- **操作手順を見る：** 解決したいこと、キー操作、メニュー操作の順番を確認できます。
- **ショートカット一覧：** よく使うキーボード操作を探せます。
- **お気に入り：** よく見る小技を同じブラウザで保存できます。
- **印刷：** 1件を詳しく、複数の小技をまとめて、またはショートカットを選んで印刷できます。

## 使い方

1. 上の「アプリを開く」からアクセスします。
2. 「やりたいことから探す」または「ショートカット一覧」を選びます。
3. キーワードを入力するか、Excel・Word・PowerPointで絞り込みます。
4. 気になる小技の「手順を見る」を押して操作を確認します。

ブラウザで使えるため、専用アプリのインストールは必要ありません。

## 収録内容

Excelの表・データ整理、Wordの文書作成、PowerPointの図形・写真加工などを収録しています。図形に文字を入れる、図形の形に写真を合わせる、入力パターンを自動補完するといった、日々の作業に役立つ操作も扱っています。

## 想定環境と注意事項

- 主に **Windows版 Microsoft 365** を想定しています。Officeのバージョンや設定によって、機能・メニュー名・操作位置が異なる場合があります。
- 掲載する説明や図は操作の参考情報です。すべての操作について、すべてのOffice環境での動作確認が完了しているわけではありません。
- お気に入りは利用中のブラウザ内に保存されます。別の端末やブラウザとの同期はありません。ブラウザのデータを消去すると失われる場合があります。
- 印刷はA4向けに整えていますが、ブラウザや印刷設定によって改ページが生じることがあります。印刷プレビューで確認してください。
- このツールはMicrosoftの公式製品ではありません。
